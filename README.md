# School Management UI

A simple, responsive school management dashboard built with only **HTML and CSS** (no JavaScript).

## Pages
- `index.html` - Dashboard
- `students.html` - Student list
- `attendance.html` - Attendance
- `fees.html` - Fees status
- `teachers.html` - Teachers
- `timetable.html` - Weekly timetable
- `style.css` - Styling for all pages

## Technologies used
- HTML5 (structure)
- CSS3 (Flexbox, Grid, media queries for responsive design)

Note: this is a UI design project with sample data.
